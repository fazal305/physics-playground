# Physics Playground

An interactive browser-based physics sandbox built with HTML5 Canvas, Vanilla JavaScript, Bootstrap 5, and jQuery.

Users can spawn objects, apply gravity, drag and throw bodies, adjust bounciness, and watch real-time physics simulation directly in the browser.

---

## Live Demo

https://fazal305.github.io/physics-playground/

---

## Features

### Physics Engine

- Custom physics engine built from scratch
- Gravity simulation
- Friction system
- Real-time motion updates
- Euler integration
- Boundary collisions
- Object-to-object collisions
- Velocity-based movement
- Kinetic energy calculations

### Shapes

- Circle spawning
- Rectangle spawning
- Triangle spawning
- Multiple size options
- Adjustable mass
- Adjustable restitution (bounce)

### Interaction

- Spawn tool
- Drag tool
- Throw objects with mouse momentum
- Delete tool
- Object selection
- Hover highlighting
- Pause and resume simulation
- Clear all objects

### Simulation Controls

- Gravity toggle
- Friction toggle
- Bounce slider
- Mass slider
- Size slider
- Color selection system

### Information Panel

- FPS counter
- Object count
- Total kinetic energy
- Selected object information
- Position tracking
- Velocity tracking
- Mass display

### Visual Design

- Dark neon interface
- Cyan and purple accents
- Responsive layout
- Canvas rendering
- Velocity arrows
- Selection glow effects
